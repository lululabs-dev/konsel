Konsel 개인정보 처리방침

시행일: 2026년 11월 23일

루루랩스 주식회사(이하 "회사")는 Konsel 맥 앱과 Konsel 내려받기 웹페이지(이하 "서비스")에서 처리하는 개인정보를 이 방침에 따라 다룹니다.

1. 핵심 원칙

  • Konsel은 사용자의 맥에서 실행됩니다. 대화, 기억, 로그인 정보는 사용자의 맥에 저장되고 회사 서버로 보내지 않습니다.
  • Konsel 계정은 없습니다. 회사는 비밀번호를 받거나 저장하지 않습니다. 각 AI에는 그 회사의 로그인 화면에서 사용자가 직접 로그인합니다.
  • 회사가 받는 것은 앱을 고치기 위한 사용 기록, 사용자가 직접 보낸 의견, 웹페이지 방문 기록뿐입니다.

2. 처리하는 정보

2.1 사용자의 맥에만 저장하는 정보

정보저장 위치목적
사용자가 정한 이름, 화면 언어~/Library/Application Support/Konsel/profile.jsonAI가 사용자를 부를 때 사용
대화 내용같은 폴더의 rooms.jsonl대화를 이어서 보기
AI가 기억하도록 저장한 문장, 저장한 날짜, 바뀌기 전 문장같은 폴더의 notes.json, ~/Konsel/Memory 폴더의 주제별 파일다음 대화에서 AI에게 전달
이미지·영상 생성 서비스 로그인 정보(접근 토큰)맥 키체인사용자 계정으로 생성 요청
생성 서비스 연결 정보같은 폴더의 creators.json로그인 유지

Konsel은 주민등록번호, 카드 번호, 계좌번호, 전화번호, 비밀번호, API 키로 보이는 내용을 AI 기억에 저장하지 않습니다.

2.2 앱 사용 기록과 의견 (선택)

앱을 고치는 데 쓰려고 아래 정보를 PostHog(독일 프랑크푸르트 서버)로 보냅니다. 앱을 처음 실행할 때 "보내기"를 고른 경우에만 보내고, 고르기 전에는 아무것도 보내지 않습니다. My 화면 설정의 "사용 기록 보내기"에서 언제든 바꿀 수 있습니다. 의견은 사용자가 의견 창에서 보내기를 누를 때만 보냅니다.

정보보내는 때보유 기간
설치마다 만든 무작위 번호, 앱 버전, macOS 버전, 화면 언어, 연결한 AI 이름아래 기록마다 함께1년
하루 동안의 앱 실행, 보낸 글, AI 답, 새 대화 개수하루에 한 번1년
AI 연결, 로그인 미완료, 오류가 난 단계와 종류(오류 원문은 보내지 않음)일어났을 때. 같은 오류는 하루에 한 번1년
사용자가 쓴 의견 글보내기를 눌렀을 때1년

대화 내용, 이름, 이메일, 파일 경로는 보내지 않습니다. IP 주소는 저장하지 않고 위치도 추정하지 않습니다.

2.3 내려받기 웹페이지 방문 기록

웹페이지를 고치는 데 쓰려고 아래 정보를 PostHog(독일 프랑크푸르트 서버)로 보냅니다. 쿠키와 브라우저 저장 공간을 쓰지 않아 다음 방문과 연결되지 않습니다. 화면 녹화와 자동 클릭 수집은 하지 않습니다.

정보보내는 때보유 기간
페이지 주소, 들어온 사이트 주소, 브라우저와 기기 종류, 화면 크기, 페이지 언어페이지를 열 때1년
시작 방법 부분까지 내려 보았는지그 부분이 화면에 보일 때 한 번1년
내려받기 버튼을 눌렀는지, 위쪽과 아래쪽 버튼 중 어느 것인지누를 때1년

IP 주소는 저장하지 않습니다. 방문 기록은 서로 연결하지 않아 개인의 관심이나 성향을 알 수 없고, 맞춤형 광고에 쓰지 않습니다. 브라우저의 추적 방지 기능으로 막을 수 있고, 막아도 페이지를 이용하는 데 영향이 없습니다.

2.4 새 버전 확인

앱은 켤 때와 6시간마다 GitHub(GitHub, Inc., 미국)에 Konsel의 최신 버전과, 지금 버전을 계속 쓸 수 있는지에 대한 정보를 요청합니다. 회사가 베타를 끝내거나 문제가 있는 버전의 사용을 멈출 때 이 정보로 앱에 안내합니다. 이 요청에는 개인정보를 담지 않지만, 인터넷 통신의 특성상 GitHub가 IP 주소를 받습니다. 회사는 이 요청의 기록을 받지 않습니다.

2.5 처리하지 않는 것

  • 회사는 이용자의 권리나 의무에 영향을 주는 자동화된 결정을 하지 않습니다.
  • 회사는 받은 정보를 AI 학습에 쓰지 않습니다.
  • 회사는 무작위 번호로만 묶인 사용 횟수를 받으며, 맥에 저장된 대화와 기억은 앱 데이터 폴더의 파일로 이용자가 직접 복사해 옮길 수 있습니다.

3. 처리 위탁과 국외 이전

회사는 2.2와 2.3의 정보를 보관하고 분석하는 일을 아래 회사에 맡깁니다.

받는 회사맡기는 일이전 국가이전 시기와 방법보유 기간연락처
PostHog Inc.사용 기록, 의견, 웹페이지 방문 기록의 보관과 분석독일(저장 서버), 미국(회사 소재지)앱을 쓰거나 웹페이지를 열 때 인터넷으로 암호화해 전송1년privacy@posthog.com

앱 사용 기록은 처음 실행할 때 "보내지 않기"를 고르거나 My 화면 설정에서 꺼서 거부할 수 있습니다. 거부해도 앱의 모든 기능을 그대로 쓸 수 있습니다. 웹페이지 방문 기록은 브라우저의 추적 방지 기능으로 거부할 수 있습니다.

4. 이용자가 연결한 AI로 보내는 대화

AI가 답하거나 이미지를 만들려면 대화 내용이 그 AI를 운영하는 회사로 갑니다. 이 전송은 이용자가 연결한 AI에 이용자의 맥에서 바로 보내는 것이며, 회사가 정보를 받아 넘기는 제3자 제공이나 국외 이전이 아닙니다. 각 회사가 받은 정보는 그 회사의 처리방침에 따라 처리되며, 처리 국가와 보유 기간도 각 회사의 처리방침에서 확인할 수 있습니다.

받는 곳가는 정보가는 때
Anthropic (Claude)대화 내용, AI가 읽은 맥의 파일 내용, 저장된 기억연결한 Claude가 답할 때
OpenAI (ChatGPT, Codex)대화 내용, AI가 읽은 맥의 파일 내용, 저장된 기억연결한 ChatGPT가 답할 때
xAI (Grok)대화 내용, AI가 읽은 맥의 파일 내용, 저장된 기억연결한 Grok이 답할 때
GitHub (Copilot)대화 내용, AI가 읽은 맥의 파일 내용, 저장된 기억연결한 Copilot이 답할 때
Anysphere (Cursor)대화 내용, AI가 읽은 맥의 파일 내용, 저장된 기억연결한 Cursor가 답할 때
Higgsfield생성 요청 문장, 참고로 넘긴 이미지연결한 Higgsfield로 이미지·영상을 만들 때

이용자가 연결한 다른 서비스(예: Supabase, GitHub)로 가는 정보는 그 서비스의 약관과 처리방침을 따릅니다.

사용자는 My 화면에서 AI 연결을 끊어 전달을 멈출 수 있습니다.

5. 이용자의 선택과 권리

  • My 화면에서 AI 연결 끊기, 로그아웃, 저장된 기억 지우기, 사용 기록 보내기 끄기를 할 수 있습니다.
  • 앱 데이터 폴더(~/Library/Application Support/Konsel)를 지우면 맥에 저장된 대화가 모두 지워집니다.
  • 회사가 받은 정보의 열람, 정정, 삭제, 처리 정지와 동의 철회를 요청할 수 있습니다. 요청은 아래 개인정보 문의 이메일로 보내며, 회사는 요청한 사람을 확인한 뒤 관련 법령이 정한 기간 안에 처리하고 결과를 알립니다. 사용 기록은 무작위 번호로만 묶여 있으므로, 요청할 때 My 화면에 보이는 설치 번호를 함께 알려 주면 찾을 수 있습니다.
  • 만 14세 미만 아동의 법정대리인도 같은 방법으로 권리를 행사할 수 있습니다.

6. 아동의 개인정보

서비스는 만 14세 이상 이용자를 대상으로 하며 만 14세 미만 아동을 대상으로 제공하지 않습니다. 회사는 만 14세 미만 아동의 개인정보를 고의로 수집하지 않으며, 수집된 사실을 알게 되면 지체 없이 삭제합니다.

7. 파기

보유 기간이 끝난 정보는 지체 없이 삭제합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다. 맥에 저장된 정보는 사용자가 앱에서 지우거나 앱 데이터 폴더를 삭제해 직접 지울 수 있습니다.

8. 안전성 확보 조치

  • AI는 사용자의 글로만 움직입니다. 대화에 연결한 폴더는 사본에서 고치고, 원본은 사용자가 합치기를 누를 때만 바뀝니다.
  • 생성 서비스의 로그인 정보는 맥 키체인에 보관하고 AI에게 넘기지 않습니다. AI가 쓸 수 있는 생성 도구는 미리 정한 목록으로 제한하고, 결제·게시·삭제 도구는 막습니다.
  • 사용 기록과 의견은 암호화된 연결(HTTPS)로 전송합니다.
  • 회사가 받은 정보는 업무에 필요한 담당자만 볼 수 있게 접근 권한을 제한합니다.

9. 방침의 변경

이 방침이 변경되는 경우 시행 7일 전에 이 페이지 또는 앱에서 안내합니다. 이용자 권리에 중대한 변경이 있는 경우 시행 30일 전에 안내합니다.

변경 이력

  • 2026년 11월 22일: 처음 시행
  • 2026년 11월 23일: 폴더 사본 작업과 연결한 다른 서비스에 관한 내용 반영
